# 05.04：退款与结算同时到达

订单完成事件触发给卖家放款的同时，客服可能批准退款。两个消费者读到同一张 `cleared` 清算单后，如果各自修改余额，就会把同一笔托管资金同时发给买卖双方。

请实现 `Apply`。要求同一订单只能产生一个资金终态；相同请求可以安全重放，相反请求必须返回冲突。余额、双边流水和状态推进属于同一事务，第二条流水失败不能留下任何中间结果。

结算净额和退款总额都必须为正；更新买家或卖家余额前还要检查 `int64` 溢出，失败时不能写入流水或改变清算状态。

运行：

```bash
go test -race -tags exercise ./exercises/05-payment-settlement/05.04-refund-settlement-race/problem
```
